Questions fréquentes

Combien d'établissements puis-je gérer avec le plan Agency ?
Le plan Agency de RepuGuard permet de gérer jusqu'à 50 établissements ou profils Google. Pour les réseaux plus importants (franchises nationales, groupes de 100+ établissements), contactez notre équipe pour une offre sur mesure avec tarification dégressive.
Les rapports white-label peuvent-ils intégrer notre logo et nos couleurs ?
Oui. Les rapports PDF sont entièrement personnalisables : logo, couleurs, nom de l'agence, message d'introduction. Chaque rapport semble créé spécifiquement par votre agence, renforçant votre valeur perçue auprès de vos clients.
Nos clients peuvent-ils avoir accès à leur propre tableau de bord ?
Oui. Vous pouvez créer des accès clients avec un périmètre limité à leurs propres établissements. Ils voient leurs avis, leurs statistiques et peuvent valider des réponses — sans voir les données de vos autres clients.
L'API RepuGuard est-elle bien documentée ?
Oui. RepuGuard fournit une documentation API complète (OpenAPI/Swagger) avec des exemples de code en JavaScript, Python et PHP. Notre équipe technique est disponible pour vous accompagner dans l'intégration.
Est-il possible de facturer la gestion de réputation à nos clients via RepuGuard ?
RepuGuard n'est pas une plateforme de facturation, mais il vous fournit toutes les données et les rapports pour justifier et valoriser votre service de réputation. La plupart de nos agences ajoutent ce service à 150-400€/mois/client par-dessus leur abonnement RepuGuard.
